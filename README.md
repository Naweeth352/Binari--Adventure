# Quran Madrasa Management System

This project provides a basic web application for managing a part-time Hifzul Quran madrasa.

## Features
- Manage students
- Manage classes
- Record enrollments and attendance

## Getting Started
1. Install dependencies: `pip install -r requirements.txt`
2. Initialize the database: `python app.py init-db`
3. Run the development server: `python app.py run`
